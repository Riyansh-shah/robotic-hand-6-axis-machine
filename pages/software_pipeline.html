Stage Details

1

CAD Design

Fusion 360 is used for all arm structural parts. The kinematic skeleton (joint axes, link lengths, DH parameters) is defined first as a parametric sketch, then link geometry is designed around it. All files are version-controlled in Autodesk cloud and exported as STEP for FEM analysis and as STL for printing.

2

Slicing — Standard & Non-Planar

PrusaSlicer handles standard planar slicing for calibration prints. For non-planar paths, a modified version of FullControl GCode Designer generates 5-axis toolpaths (X, Y, Z + nozzle tilt I, J). Future integration with Slicer4RTN (a non-planar slicer research tool from TU Delft) is planned for fully automated curved-surface slicing.

3

IK Solver (Python)

The core Python solver implements the analytical decoupled IK from Chapter 3. Key libraries: NumPy for matrix operations, SciPy for spline fitting. Typical processing time for a 200-waypoint segment: ~12ms on Raspberry Pi 4.

# Core IK call
def ik_solve(pose: np.ndarray,
             q_prev: np.ndarray) -> np.ndarray:
    wc = compute_wrist_center(pose)
    q123 = solve_position(wc)
    q456 = solve_orientation(pose, q123)
    return select_nearest(q123+q456, q_prev)
4

Trajectory Generation

SciPy's CubicSpline fits a smooth trajectory through all IK-solved joint angles. The spline is evaluated at 1kHz to produce the command stream. Velocity and acceleration continuity are enforced by natural boundary conditions at the spline knots.

from scipy.interpolate import CubicSpline
cs = CubicSpline(t_waypoints,
                   joint_angles,
                   bc_type='natural')
t_fine = np.arange(0, T_total, 0.001)
q_stream = cs(t_fine) # 1kHz commands
