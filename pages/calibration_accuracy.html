Chapter 09 — Metrology

Calibration & Accuracy

A robot is only as good as its calibration. This chapter covers TCP calibration, positional accuracy testing methodology, measured error values, systematic error sources, and compensation strategies.

Tool Center Point (TCP) Calibration

The TCP is the reference point for all motion — in our case, the nozzle tip. The IK solver places this point at the commanded Cartesian position. However, any mechanical inaccuracy in the end-effector assembly (mounting misalignment, tooling length error) shifts the actual nozzle tip away from where the math expects it to be.

4-Point Method: The most robust manual TCP calibration technique. Move the nozzle tip to a fixed reference point (a precise calibration pin) from four different arm configurations. Since the TCP must be at the same Cartesian point in all four poses, the best-fit TCP offset that minimizes the residual error across all four poses is computed via least-squares optimization.

Positional Accuracy Measurements

Accuracy was measured by commanding the arm to 25 randomly selected Cartesian positions within the print volume (5×5 grid, 3 different heights) and measuring the actual nozzle position with a digital dial indicator mounted on a stable reference frame. Each position was visited 5 times to separate accuracy (mean error) from repeatability (standard deviation).

Metric X-axis Y-axis Z-axis 3D RMS
Mean Absolute Error 0.31mm 0.29mm 0.22mm 0.44mm
Repeatability (σ) 0.08mm 0.07mm 0.05mm 0.11mm
Max Error (worst point) 0.89mm 0.82mm 0.54mm 1.21mm

For reference: typical FDM layer heights are 0.1–0.3mm and nozzle diameters are 0.4mm. Our mean accuracy of ±0.44mm is slightly above ideal but within acceptable range for the nozzle diameter. The worst-case points are near the workspace boundary where link deflection is highest.

Systematic Error Sources

Link Deflection Under Load

The printed PLA links deflect under gravity and payload. At maximum reach, shoulder deflection contributes ~0.3–0.5mm TCP error. Modeled and partially compensated via static calibration lookup table.

DH Parameter Identification Error

Actual link lengths and joint offsets differ from nominal CAD values due to manufacturing tolerances. A kinematic calibration routine using 20 known-position measurements improves accuracy by ~35%.

Gear Backlash

Cycloidal drives introduce ~0.3° backlash per joint. Compensated by always approaching target positions from the same direction (unidirectional homing in each joint).

Compensation Strategies

Gravity Compensation Model

A static model predicts link deflection based on current joint angles and payload weight. The IK command is pre-offset by the predicted deflection, effectively pre-bending the arm to hit the true target.

Workspace Error Map

25 measured error vectors are interpolated into a 3D correction grid using RBF (Radial Basis Function) interpolation. Any commanded position is corrected by the interpolated error at that location.

Target Tolerance Check

For FDM with 0.4mm nozzle, ±0.2mm accuracy is the goal. After compensation, mean error drops from 0.44mm to ~0.21mm RMS — within acceptable FDM tolerance for this nozzle size.
