================================================================================
TEST METHODOLOGY
================================================================================

1. UNIT TESTING APPROACH:
   - Each function tested in isolation with known inputs/outputs
   - Fixtures provide consistent test data
   - Parametrized tests cover multiple configurations

2. INTEGRATION TESTING:
   - FK-IK roundtrips verify modules work together
   - Multi-segment trajectories test chaining logic
   - File parsing tests with realistic G-code samples

3. ASSERTION TYPES:
   - npt.assert_array_almost_equal() for numerical precision (decimal=4-5)
   - pytest.approx() for floating-point comparison
   - Shape and dimension checks for array validation
   - Exception testing with pytest.raises()

4. TOLERANCE LEVELS:
   - Position tolerance: 1e-4 m (0.1 mm)
   - Angle tolerance: decimal=5 in matrix comparisons
   - Velocity tolerance: 10% of limit for discrete profiles
   - Rotation orthogonality: decimal=5
